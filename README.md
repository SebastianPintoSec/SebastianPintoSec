## Trabajo técnico destacado

### Modernización de infraestructura de seguridad y conectividad
Participación en un proyecto residencial que integró CCTV IP, conmutación PoE, enlaces entre racks mediante fibra óptica y Ethernet, alimentación respaldada mediante UPS y control de acceso. El trabajo incluyó implementación, pruebas y documentación de entrega.

### Integración de gateway empresarial
Trabajo técnico con un gateway Ubiquiti UXG-Pro en un entorno educacional, considerando conectividad WAN, integración con infraestructura existente y diagnóstico de comportamiento de interfaces y rutas.

### ZN Cloud / ZN Remote — Desarrollo interno
Participación en el diseño y evolución de una solución de acceso remoto a infraestructura de red, con gestión de sitios y activos, túneles, controles sobre el ciclo de vida de las sesiones y automatización de acceso técnico.
